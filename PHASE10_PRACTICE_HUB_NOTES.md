# Phase 10: merge of the v7 textbook build, and the Practice hub

## 1. The v7 zip was merged into this site (2026-10-24)
`LearningAI_Textbook_Rebuild_v7.zip` turned out to be this site plus a textbook-companion layer. 108 new files were added (Algorithm Design proof labs and 8 downloadable Python labs, ISLR with R labs, Operating Systems and Computer Networking courses, the Textbooks atlas at `#/books`, Manim scene sources in `video/manim/`, build tools, coverage trackers). Kept from this project: `.gitignore`, `video/build-storyboards.cjs`, `video/README.md` and the whole video work. The zip's older `video/out/` files were regenerated.
After the merge every Node suite and every browser suite passes. Three fixes to the zip's own tests: its browser tests hard-coded `/usr/bin/chromium` (now `tests/_browser.py`, which also finds Edge or Chrome), two old release tests asserted lesson counts that v7 superseded (now minimums), and several Python tests need `PYTHONUTF8=1` on Windows. `tests/local-reader-smoke.py` needs PyMuPDF (`fitz`) and your own PDF, so it was not run.

### Where the material comes from
- **Quiz questions:** copied unchanged from three Microsoft repositories, all MIT, Copyright (c) Microsoft Corporation: [ML-For-Beginners](https://github.com/microsoft/ML-For-Beginners) (156 questions), [AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners) (145) and [Data-Science-For-Beginners](https://github.com/microsoft/Data-Science-For-Beginners) (120). Only the English quiz JSON files were fetched, not the 1.4 to 2.2 GB repositories. Options keep the source order except that the page shuffles them at run time, and questions whose options depend on order ("both of the above", true/false) are never shuffled.
- **Reference code:** unchanged MIT files from [TheAlgorithms/Python](https://github.com/TheAlgorithms/Python) (24 files), [aima-python](https://github.com/aimacode/aima-python) (`search.py`, `games.py`, `csp.py`, `mdp.py`), [Sutton and Barto implementations](https://github.com/ShangtongZhang/reinforcement-learning-an-introduction) and [micrograd](https://github.com/karpathy/micrograd), each with its LICENSE, under `third_party/`. They are shown as "compare with" and are **not** the graded code. The k-means, gradient-descent and least-squares labs link to the Apache-2.0 [Hands-On ML notebooks](https://github.com/ageron/handson-ml3) without copying anything.
- **Everything else is original:** lab prompts, starters, hidden tests, sample solutions, hints and the page.
- **Licence audit:** 30 repositories were checked through the GitHub API on 2026-10-24 (`docs/SOURCES_AUDIT.md`). Copying was limited to MIT repositories. Repositories with no licence file (OSTEP code and homework, Build Your Own X) or with mixed or unreported licences (Dive into Deep Learning, LLMs from Scratch, CleanRL) are link only, as are those that need cloud credentials, GPUs or servers (agents and generative-AI courses, LangChain Academy, BusTub, the blockchain demo) and the libraries you listed (JupyterLite, Mermaid, Observable Plot, TensorFlow Playground), which are better loaded than copied. A test enforces "unclear licence means link only" and "only MIT is copied".
- Each downloaded file was checked against its git blob hash from the GitHub tree before it was added (with retries, because the network dropped connections twice), nothing downloaded was executed, and `third_party/MANIFEST.json` records the SHA-256 of every bundled file. See `THIRD_PARTY_NOTICES.md`.

The page shows each notebook with its source, licence, cell count, the packages it imports and whether it could run with browser Python (10 notebooks plausibly can; the rest need scikit-learn extras, statsmodels, PyTorch, TensorFlow or API keys). It offers **Open in Colab**, **Download** and the GitHub link. Notebooks are never executed or rendered by this site: nothing from a notebook, including its saved outputs, is put on the page. Course texts are shown as plain text.
**Not copied, on purpose:** repositories with no licence file (OSTEP code and homework, Build Your Own X), a mixed or unreported licence (Dive into Deep Learning, LLMs from Scratch, CleanRL) or a copyleft or non-commercial licence in the atlas (Python Data Science Handbook text, GPL fastbook). Putting those on a public site would republish other people's work without permission, whatever the instruction here; they remain links on the Sources page. Also not copied: whole repositories (the Microsoft courses are 1.4 to 6.5 GB each with translations and images) and the Microsoft agents and generative-AI notebooks, which need cloud credentials.
Apache-2.0 asks that changes be stated: there are none, and `third_party/MANIFEST.json` lets anyone verify each file is byte-for-byte the original.

### How the labs are checked
`tests/practice-labs.py` runs every lab in real Python, each variant in its own process with a 30 s limit: the sample solution passes, the starter fails, and 55 deliberately wrong variants (a no-op, a linear scan instead of binary search, greedy best-first instead of A*, a greedy instead of dynamic programming, and so on) fail. This found three weak tests before release (a linear scan passed the binary-search test, a wrong BFS variant looped forever, greedy best-first passed the A* test on small grids) and all were fixed. Hidden tests compare the learner's code with brute force or an independent reference on seeded random inputs, so the labs cannot be passed by hard-coding answers.

### Tests added
`node tests/practice-hub.test.cjs` (bundled files unchanged, quiz data identical to the MIT source, labs attributed and complete), `python tests/practice-labs.py`, `python tests/practice-experience.py` (real browser: a perfect quiz run, a run with a miss, a lab failing then passing in Pyodide, saved progress, phone width, zero JS exceptions; needs a static server on port 8000 and internet for Pyodide). Regenerate the data with `python tools/build_practice_hub.py`.

### Limits
Python needs internet the first time (Pyodide, about 10 MB, from jsDelivr) like the existing Python labs; a dropped connection shows "Could not load Python" and a retry fixes it (it happened once in the test runs). Progress lives only in this browser. A learner who writes an infinite loop will freeze the tab until they reload (Pyodide runs on the page thread). The quizzes cover machine learning, AI foundations and data science; there are no quizzes yet for the Prompt, LLM, Agents, Databases, Operating Systems or Networking courses, and no repository on your list supplied any. The labs have no database, operating-systems or LLM tasks. Not done: JupyterLite, DuckDB-Wasm, Mermaid and Observable Plot were not added (no lesson needs them yet), and the Textbooks material still has its known gaps. Practice questions are not part of the guessability guard that protects the course quizzes, because they are third-party material that is kept unchanged. The Textbooks, algorithm and ISLR content from the zip is described in `TEXTBOOK_REBUILD_STATUS_v7.md`, including what is still incomplete (83 of 98 algorithm-design sections have no lab).
