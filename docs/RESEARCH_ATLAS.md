## Important limitations

- This is a research index of resources and links, not a collection of copied third-party textbooks, figures, assignment solutions, or PDFs.
- Reviewed web search results confirm the repository descriptions and canonical URLs; the repositories were **not cloned or executed** and no HTTP crawl or per-file rights audit was performed.
- Resource licensing can differ across code, text, images, datasets, video and vendor branding; default to outbound links.
- Some references require APIs, cloud accounts or local Linux/GPU; those are not browser-only GitHub Pages exercises.
- Never represent LearningAI as issuing a provider’s recognized certification.

## Recommended LearningAI build order

1. **Book-aligned experiments:** RL Sutton & Barto figure reproduction, ISLP official labs, AIMA search/CSP, D2L gradient graph.
2. **Student assessment:** use the Microsoft pre/post quiz structure as a *design reference* but write original questions, explanations and test cases.
3. **Interactive textbook figures:** browser charts with SVG/Canvas and parameter sliders; prefer original implementations over screenshots of publisher figures.
4. **Runtime:** retain existing Pyodide and SQLite; consider JupyterLite for notebook import and DuckDB-Wasm for analytical SQL.
5. **Advanced work:** provide repository links for xv6, Mininet, CS336, Gymnasium and BusTub instead of pretending their programs can run on static hosting.
6. **Portfolio:** end-to-end artifact + tests + evaluation + reproducibility and a public student repo (only where class integrity permits).

## Site import

`learningai_worldwide_resources.json` is machine-readable; `index.html` provides a dependency-free, single-file searchable directory. To incorporate into existing site, add a Resources route and render records grouped by `tracks`, `resource_type`, `priority`; do not overwrite existing course modules or import copyrighted external prose.
